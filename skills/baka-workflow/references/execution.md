# 执行环境

- 自建脚本、程序、构建产物、运行数据及需复用的文件放已授权工作目录；中间文件放其 `work/`。不放 `/tmp`、`/private/tmp`、`/var/tmp` 或系统临时目录。
- 工具自动产生的临时文件、用户临时附件可读取；需长期依赖时先复制到任务目录，不以临时路径作为服务运行目录。
- 二进制程序、构建和测试脚本通过宿主的 shell 工具启动；启动目标服务优先 `exec <命令>`，构建／测试脚本可正常启动子进程。不要求检查 PID、PPID 或祖先进程链，不为调整进程关系中断现有任务。
- 不通过换路径、复制程序、改变启动入口绕过权限或执行阻断。遇阻断先核实原因，在权限范围内修正；没有证据不推断 yunke 或其他宿主的拦截机制。
